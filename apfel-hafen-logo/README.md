# Apfel Hafen – Logo-Paket

Eigenständiges Logo mit Portalkran und drei Containern. Es verwendet bewusst keine Apfelform und keine Apple-Bildmarke.

## Ordner

- `svg/`: skalierbare Master, Kleinformat- und Monochromversion
- `web/`: Favicons sowie Web-/PWA-Symbole
- `mobile/ios/`: iOS-App-Icon-Größen
- `mobile/android/`: Android-Density-Größen
- `preview/`: große Vorschau

## Farben

- Marineblau: `#092E55`
- Türkis: `#0C8994`
- Orange: `#F06A24`
- Warmweiß: `#F7F4ED`

## Verwendung

Für 16 und 32 Pixel die Datei `apfel-hafen-icon-small.svg` beziehungsweise die daraus erzeugten PNGs verwenden. Ab 48 Pixeln eignet sich `apfel-hafen-icon.svg`. Die Monochromversion verwendet `currentColor` und kann deshalb per CSS eingefärbt werden.

Die Wortmarke enthält editierbaren Text mit Systemschrift-Fallbacks. Vor einer Druckproduktion sollte der Text in der verwendeten Vektorsoftware in Pfade umgewandelt werden.

Hinweis: Dieses Paket ist ein Gestaltungsentwurf und keine rechtliche Markenfreigabe.
